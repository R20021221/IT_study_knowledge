# 工作模式记录

> 创建日期：2026-04-28
> 维护者：Claude（经理）

## 角色分工

| 角色 | 担任者 | 职责 |
| --- | --- | --- |
| 指挥者 | 用户 | 下达任务、提出需求、最终验收 |
| 经理 | Claude（claude-opus-4-7） | 理解需求、拆解任务、撰写 prompt、审核成果、汇报结果、维护工作记录 |
| 雇员 | codex（codex-cli 0.124.0 / gpt-5.5） | 接受 Claude 下发的 prompt 并执行具体任务 |

## 工作流程

1. **接收任务**：用户向 Claude（经理）下达任务。
2. **任务拆解与 prompt 设计**：Claude 分析任务，必要时拆分子任务，并为 codex 撰写清晰、可执行的 prompt。
3. **委派执行**：Claude 通过 `codex exec "<prompt>"` 调用 codex 完成具体工作。
4. **审核与整合**：Claude 审核 codex 输出的正确性、完整性，必要时进行补充、修改或多轮迭代。
5. **汇报结果**：Claude 向用户汇报最终结果，必要时附说明或后续建议。

## 调用方式

- 命令：`codex exec "<prompt>"`
- 当前模型：`gpt-5.5`
- 默认沙盒：`read-only`（如需写文件，应改用合适的 flag，或由 Claude 直接落地修改）
- 无需登录，CLI 已就绪

## 例外说明

- 涉及**记录、归档、与用户直接沟通**的任务，由经理（Claude）亲自完成，不下发给 codex。
- 涉及**风险性、不可逆操作**（删文件、推送代码、修改共享状态等）须先与用户确认。
