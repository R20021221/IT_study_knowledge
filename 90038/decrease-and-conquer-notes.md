## 一、Decrease-and-Conquer 概述

**核心思想**：将规模为 $n$ 的问题，通过递减问题规模来求解——即将问题的解表示为规模更小的同类问题的解，再在此基础上构建更大规模问题的解。

分为两大类：
- **Decrease-by-a-Constant（按常数递减）**：每次将问题规模减少固定常数（通常为 1）
- **Decrease-by-a-Factor（按因子递减）**：每次将问题规模按比例缩小（通常减半）

## 二、Lecture 9：按常数递减（Decrease-by-a-Constant）

### 2.1 拓扑排序（Topological Sorting）

#### 背景与定义

**拓扑序（Topological Order）** 是对有向无环图（DAG）节点的一种线性化排列。在很多任务调度问题中都有应用，例如课程选课（每门课有前置要求）。

**正式定义**：给定有向无环图 $G = \langle V, E \rangle$，**拓扑排序**的目标是对 $V$ 中所有节点排序，使得：

$$\text{对于每条边 } (u, v) \in E，\text{节点 } u \text{ 必须排在节点 } v \text{ 之前。}$$

满足上述条件的节点顺序称为该图的一个**拓扑序**。

**关键性质**：

> 一个有向图 $G$ 存在拓扑序，**当且仅当** $G$ 是无环的（即 $G$ 是 DAG）。

#### 示例

对于如下图：
```
a → c → e
↑   ↑   ↓
b → d   f
```
共有四种不同的拓扑线性化方式，其中一种为：`b → a → d → c → e → f`

---

### 2.2 基于 DFS 的拓扑排序

#### 算法步骤

1. 选取任意一个**入度为 0**（即 $\deg_{\text{in}}(u) = 0$）的节点 $u$；
2. 从 $u$ 出发执行 DFS，记录节点**从栈中弹出的顺序**；
3. 将所有节点按弹出顺序**逆序排列**，即为拓扑序。

#### 时间复杂度

$$O(|V| + |E|)$$

#### 正确性分析

算法的正确性基于以下两个观察：

1. 在 DAG 中，节点 $v$ 被弹出栈，**当且仅当**从 $v$ 可达的所有节点都已被遍历完毕。
2. "逆序弹出"确保 $v$ 会排在其所有可达节点之前。

#### DFS 拓扑排序示例

从节点 $b$ 出发，按字母序处理，得到如下弹出顺序（括号内为弹出序号）：

| 弹出序号 | 节点 |
|---------|------|
| 1       | e    |
| 2       | f    |
| 3       | c    |
| 4       | a    |
| 5       | d    |
| 6       | b    |

逆序后得到拓扑序：`b, d, a, c, f, e`

---

### 2.3 基于 Decrease-and-Conquer 的拓扑排序

#### 递归思路

对 DAG $G = \langle V, E \rangle$，可以**增量式**地构造拓扑序：

1. 在 $G$ 中选取任意一个**入度为 0** 的节点 $u$；
2. 将 $u$ 追加到当前拓扑序的末尾；
3. 从 $G$ 中移除 $u$ 及其所有关联边；
4. 对新的 $G$ 递归计算拓扑序。

**为什么可以直接将入度为 0 的节点排在最前面？**
因为入度为 0 意味着没有任何节点需要排在 $u$ 之前，所以将 $u$ 置于当前序列首位是安全的。

每次迭代将 $G$ 中节点数减少 1，这正是 **Decrease-by-a-Constant** 的体现。

#### 非递归（迭代）版本

令 $G' \leftarrow G$，重复以下步骤直至 $G'$ 为空：

1. 在 $G'$ 中选取入度为 0 的节点 $u$；
2. 将 $u$ 追加到拓扑序；
3. 从 $G'$ 中移除 $u$ 及所有关联边。

#### 时间复杂度分析

**朴素实现**（每次遍历所有节点寻找入度为 0 的节点）：

- 每次迭代找节点需 $O(|V(G')|)$，删除节点需 $O(\deg_{\text{out}}(u))$；
- 共 $|V|$ 次迭代，总时间：

$$O(|V|^2 + \sum_{u \in V} \deg_{\text{out}}(u)) = O(|V|^2 + |E|) = O(|V|^2)$$

**优化版本**（使用辅助数据结构）：

存在一种简单数据结构，可将总时间降至 $O(|V| + |E|)$，满足：

- 空间占用：$O(|V|)$
- 找到一个入度为 0 的节点：$O(1)$
- 每次迭代更新维护：$O(\deg_{\text{out}}(u))$

> **练习提示**：用一个数组维护所有节点的当前入度，配合一个队列存储当前入度为 0 的节点，即可实现上述优化。

## 三、Lecture 10：按因子递减（Decrease-by-a-Factor）

### 3.1 概述

**Decrease-by-a-Factor** 是 Decrease-and-Conquer 的一种更高效的变体，每次将问题规模按固定比例（如 $1/2$、$1/3$ 等）缩减，通常可以实现**对数级别**的时间复杂度。

最典型的例子是**二分搜索（Binary Search）**。

---

### 3.2 二分搜索（Binary Search）

#### 算法描述

给定**非降序排列**的数组 $A$，查找目标值 $k$：

1. 取中间元素 $A[m]$ 与 $k$ 比较：
   - 若 $A[m] = k$：找到，返回；
   - 若 $A[m] < k$：在右半部分 $A[m+1..n-1]$ 中递归搜索；
   - 若 $A[m] > k$：在左半部分 $A[0..m-1]$ 中递归搜索。

```
         = k?
          ↓
A[0] ··· A[m-1]  A[m]  A[m+1] ··· A[n-1]
若A[m]>k在此搜索        若A[m]<k在此搜索
```

#### 复杂度分析

递推关系（最坏情况，$k$ 不在数组中）：

$$C(n) = \begin{cases} 1 & \text{if } n = 1 \\ C(\lfloor n/2 \rfloor) + 1 & \text{if } n > 1 \end{cases}$$

**闭合形式**：

$$C(n) = \lfloor \log_2 n \rfloor + 1$$

**最坏时间复杂度**：$O(\log n)$

> 实例：在 1,000,000 个元素中搜索，最坏情况只需 **20 次**比较。

---

### 3.3 大数幂运算（Large Power Computation）

#### 问题描述

给定正整数 $a > 0$ 和整数 $n \geq 0$，计算 $a^n$。

#### 算法（Decrease-by-a-Factor）

- 若 $n = 0$：返回 1；
- 若 $n$ 为**偶数**：递归计算 $a^{n/2}$，返回 $a^{n/2} \cdot a^{n/2}$；
- 若 $n$ 为**奇数**：递归计算 $a^{(n-1)/2}$，返回 $a^{(n-1)/2} \cdot a^{(n-1)/2} \cdot a$。

#### 复杂度分析

每次迭代将指数 $n$ 减半，每步至多做 2 次乘法，故总时间复杂度为：

$$O(\log n)$$

---

### 3.4 第 $k$ 小元素问题（$k$-Selection Problem）

#### 问题描述

给定含 $n$ 个整数的数组 $A$ 和整数 $1 \leq k \leq n$，返回 $A$ 中**第 $k$ 小**的元素。

#### 简单情形

- $k = 1$ 或 $k = n$：扫描一次数组即可；
- $A$ 已排序：$O(1)$ 直接返回 $A[k-1]$。

#### 为什么不直接排序？

先排序（$O(n^2)$ 或 $O(n \log n)$）再取第 $k$ 个元素，功能上可行，但是**过度杀伤（overkill）**——我们希望找到一个直接求解的高效方法。

---

### 3.5 数组划分（Partitioning）

**划分（Partitioning）**是 $k$-Selection 算法的核心子程序：

以**枢轴元素（pivot）** $p$ 对数组 $A$ 进行重排，使得：

$$\text{所有} \leq p \text{ 的元素在 } p \text{ 左侧，所有} > p \text{ 的元素在 } p \text{ 右侧}$$

```
[p]  ⟹  [all ≤ p | p | all > p]
```

---

### 3.6 Lomuto 划分算法

#### 变量定义

- $s$：当前已见到的最后一个 $\leq p$ 的元素下标，初始 $s \leftarrow lo$；
- $i$：下一个待扫描的元素下标，初始 $i \leftarrow lo + 1$。

#### 算法伪代码

```
p ← A[lo]; s ← lo
for i ← lo + 1 to hi do:
    if A[i] ≤ p then:
        s ← s + 1
        swap(A[s], A[i])
swap(A[lo], A[s])
return s   // s 为 pivot p 的最终位置
```

#### 循环不变量（示意图）

```
lo      s       i      hi
[p | ≤p | >p | 未扫描]
```

#### 示例追踪

初始数组（pivot = 72）：`72  29  64  86  33  89  38  32  94  42`

| 步骤 | 数组状态 |
|------|---------|
| 初始 | **72** *29* 64 86 33 89 38 32 94 42 |
| i=2  | 72 **29** *64* 86 33 89 38 32 94 42 |
| i=3  | 72 29 **64** *86* 33 89 38 32 94 42 |
| i=4  | 72 29 64 **33** 86 *89* 38 32 94 42（swap 33,86）|
| i=5  | 72 29 64 33 **38** 89 *86* 32 94 42（swap 38,89）|
| i=6  | 72 29 64 33 38 **32** 86 *89* 94 42（swap 32,86）|
| i=7  | 72 29 64 33 38 32 **42** 89 94 *86*（swap 42,86）|
| 最终 | **42** 29 64 33 38 32 **72** 89 94 86（swap pivot）|

最终 pivot 72 落在下标 6（s = 6）。

---

### 3.7 QuickSelect 算法

#### 算法思路

利用 Lomuto 划分找到 pivot $p$ 的最终位置 $s$，根据 $s$ 与目标位置 $k$ 的关系决定在哪一侧递归：

#### 伪代码

```
function QUICKSELECT(A[·], lo, hi, k):
    s ← LOMUTOPARTITION(A, lo, hi)
    if s - lo + 1 = k then
        return A[s]
    else if s - lo + 1 > k then
        QUICKSELECT(A, lo, s - 1, k)
    else
        QUICKSELECT(A, s + 1, hi, k - (s - lo + 1))
```

**逻辑解释**：
- $s - lo + 1$：pivot 在当前子数组中的排名（从 1 起）；
- 若排名等于 $k$：找到，直接返回；
- 若排名大于 $k$：第 $k$ 小在左半部分；
- 若排名小于 $k$：第 $k$ 小在右半部分，$k$ 相应减去左侧元素个数。

#### 示例：寻找第 5 小元素

数组：`72  29  64  86  33  89  38  32  94  42`

**第一轮**（pivot = 72，s = 7，排名 = 7 > 5）：
→ 递归左侧：`42  29  64  33  38  32`，lo=1, hi=6, k=5

**第二轮**（pivot = 42）：
```
42  29  64  33  38  32
→ 经 Lomuto 划分后：
32  29  33  38  42  64
```
42 的最终位置 s = 5，排名 = 5 = k

→ **返回 42**

---

### 3.8 QuickSelect 复杂度分析

#### 最坏情况

若每次选取的 pivot 极差（每次只将数组长度减少 1）：

$$C(n) = n + (n-1) + (n-2) + \ldots + 1 = \frac{n(n-1)}{2} \in O(n^2)$$

#### 最好情况（"好的" pivot）

若每次 pivot 使左右两部分长度均 $\leq \frac{2}{3}$ 的当前数组长度：

$$C(n) \leq C\!\left(\frac{2}{3} \cdot n\right) + n$$

展开递归：

$$C(n) \leq n + \frac{2}{3}n + \left(\frac{2}{3}\right)^2 n + \ldots = \frac{n}{1 - \frac{2}{3}} = 3n \in O(n)$$

---

### 3.9 随机化 QuickSelect（Randomized QuickSelect）

#### 核心思想

通过**随机化**选取 pivot，以期望时间 $O(n)$ 解决 $k$-Selection 问题。

#### 算法实现

在 QuickSelect 的每次迭代中：

1. 从当前数组 $A[lo, hi]$ 中**均匀随机**选取 pivot $p$；
2. 用 $p$ 对 $A[lo, hi]$ 进行 Lomuto 划分；
3. 若左侧 $A[lo, s-1]$ 和右侧 $A[s+1, hi]$ 的长度**均** $\leq \frac{2}{3} \cdot |A[lo, hi]|$：
   - 接受此 pivot，进入下一轮递归；
4. 否则：**重复**第 1 步，重新随机选取 pivot。

#### 正确性与期望复杂度分析

**什么是"好的" pivot？**
一个 pivot 是"好的"，当且仅当它处于 $A[lo, hi]$ 排序后的**中间三分之一**范围内。

**好 pivot 的概率**：

$$P(\text{good pivot}) \geq \frac{1}{3}$$

**期望试验次数**：在期望意义下，最多需要 **3 次**尝试即可找到一个好 pivot。

**每次迭代的期望代价**：$O(|A[lo, hi]|)$

**总体运行时间**：

由于每次迭代至多缩减 $2/3$ 的数组规模（期望），整体时间复杂度为：

$$O(n) \quad \text{（期望）}$$

## 四、知识点总结对比

| 算法 | 策略 | 时间复杂度 |
|------|------|-----------|
| 拓扑排序（DFS） | Decrease-by-1（通过 DFS） | $O(\|V\| + \|E\|)$ |
| 拓扑排序（朴素迭代） | Decrease-by-1 | $O(\|V\|^2)$ |
| 拓扑排序（优化迭代） | Decrease-by-1 + 辅助数据结构 | $O(\|V\| + \|E\|)$ |
| 二分搜索 | Decrease-by-Factor（$\times 1/2$） | $O(\log n)$ |
| 大数幂运算 | Decrease-by-Factor（$\times 1/2$） | $O(\log n)$ |
| QuickSelect（最坏） | Decrease-by-Factor（极端情况退化） | $O(n^2)$ |
| QuickSelect（好 pivot） | Decrease-by-Factor（$\times 2/3$） | $O(n)$ |
| Randomized QuickSelect | 随机化 + Decrease-by-Factor | $O(n)$（期望） |

## 五、重要公式速查

$$\text{二分搜索比较次数：} C(n) = \lfloor \log_2 n \rfloor + 1$$

$$\text{几何级数求和：} \sum_{i=0}^{\infty} r^i = \frac{1}{1-r}, \quad |r| < 1$$

$$\text{QuickSelect（好pivot）：} C(n) \leq \frac{n}{1 - 2/3} = 3n \in O(n)$$
