## Algorithmic Problem Framing / 算法问题建模

Covered lectures: [lec01, lec02, lec03, lec05, lec14]

### Core Structure / 核心结构

- Algorithmic problem / 算法问题：不是一个具体题目，而是一类 input instances 的通用问题。 [lec01]
- Problem instance / 问题实例：属于某个算法问题的一份具体输入。 [lec01]
- Algorithm / 算法：有限、无歧义、可终止的步骤序列，必须适用于所有 well-formed input。 [lec01]
- Input-output contract / 输入输出契约：算法要把任意合法输入转换成规定输出，这是后续 correctness 和 complexity 分析的基础。 [lec01]
- Problem-solving workflow / 解题流程：理解问题、选择计算方式、选择设计策略、设计 data structures、检查正确性、trace examples、分析 cost。 [lec01]
- Abstraction / 抽象：把问题表面细节转成更简单的结构，例如 mutilated checkerboard problem 中用棋盘颜色暴露不可能性。 [lec02]
- Algorithm and data structure / 算法与数据结构：algorithm 负责 transform data，data structure 负责 organize data 以服务算法。 [lec02]
- Abstract Data Type, ADT / 抽象数据类型：只规定 data items 和 operations 的 contract，把概念和具体 implementation 分离。 [lec02]
- Theoretical Computer Science style / 理论计算机科学风格：使用抽象、数学化、语言无关的方式定义概念和证明结论。 [lec03]
- Hardness awareness / 难度意识：表面相似的问题可能难度完全不同，例如 Hamiltonian tour 与 Eulerian tour。 [lec05]
- Transform-and-conquer mindset / 变治思维：先改变 instance、representation 或 problem form，再求解。 [lec14]

### Prerequisite Foundations / 前置基础

- Sets, relations, functions / 集合、关系、函数：用于定义 graph、mapping、input-output relation 和抽象问题族。 [Prereq]
- Basic proof logic / 基础证明逻辑：用于证明算法正确性，而不是只靠样例测试。 [Prereq]
- Pseudocode literacy / 伪代码阅读能力：用于跨编程语言理解算法。 [Prereq]
- Discrete structures / 离散结构：用于在具体例子、形式定义和算法模型之间切换。 [Prereq]

### Beyond-Lecture Extensions / 进阶延伸

- Computability theory / 可计算性理论：研究哪些问题原则上能被 algorithm 解决。 [Beyond Lec]
- Reductions / 归约：把一个问题转换成另一个问题，用于迁移算法或证明 hardness。 [Beyond Lec]
- Algorithm engineering / 算法工程：研究理论算法在真实实现中的表现。 [Beyond Lec]
- Complexity classes / 复杂度类：形式化 efficient solvability 与 hardness，例如 `P` 和 `NP`。 [Beyond Lec]

### Connections / 关联

- Input-output contract 是比较 brute force、recursion、sorting、graph traversal、trees 等算法方案的共同基础。 [lec01, lec05, lec06, lec08, lec11, lec15]
- Abstraction 与 representation choice 直接连接到 transform-and-conquer、BST、heap 和 graph representation。 [lec02, lec07, lec13, lec14]

## Computational Model And Complexity Analysis / 计算模型与复杂度分析

Covered lectures: [lec03, lec04, lec06, lec10, lec11, lec12, lec13, lec15]

### Core Structure / 核心结构

- Word RAM model / 字长随机访问机模型：把计算抽象成 memory cells 与 CPU atomic operations。 [lec03]
- Atomic operations / 原子操作：包括 register initialization、arithmetic、comparison/branching、memory access，并通常视作 unit-cost。 [lec03]
- Running time cost / 运行时间成本：用输入规模 `n` 下执行的原子操作数量衡量。 [lec03]
- Space consumption / 空间消耗：用算法运行中 touched memory cells 的 footprint 衡量。 [lec03]
- Complexity function / 复杂度函数：描述 time 或 space 随 input size 增长的趋势。 [lec03]
- Worst-case analysis / 最坏情况分析：考察固定输入规模下最难输入带来的成本。 [lec03]
- Expected analysis / 期望分析：当 input 或 algorithm 有 randomness 时，用 expectation 衡量成本。 [lec03, lec10, lec11]
- Amortization / 摊还视角：关注一串 operations 的总体平均成本，而不是单次操作最坏成本。 [lec03]
- Big-O / 大 O：asymptotic upper bound，表示增长不快于某函数到常数因子。 [lec03]
- Big-Omega / 大 Omega：asymptotic lower bound，表示增长不慢于某函数到常数因子。 [lec03]
- Big-Theta / 大 Theta：tight bound，同时属于 Big-O 和 Big-Omega。 [lec03]
- Growth hierarchy / 增长阶层级：`O(1)`, `O(log n)`, polynomial, `O(n log n)`, exponential, super-exponential 是比较算法规模表现的基本尺子。 [lec03]
- Establishing growth rate / 建立增长率：可用 limits 与 L'Hopital's rule 比较 asymptotic functions。 [lec04]
- Loop counting / 循环计数：MaxElement、Selection Sort、Matrix Multiplication 分别展示 linear、quadratic、cubic 级别分析。 [lec04]
- Recursive cost equations / 递归成本方程：recursive algorithm 的结构通常会直接生成 recurrence relation。 [lec04, lec06]
- Telescoping expansion / 展开法：反复代入 recurrence，观察总成本如何累积。 [lec04, lec06]
- Logarithm base irrelevance / 对数底数无关：constant base 的 logarithms 在 asymptotic notation 中同阶。 [lec04]
- Euclid's algorithm analysis / 欧几里得算法分析：modulo 操作使问题规模按 factor 下降，可类比 binary search 的分析。 [lec01, lec04]
- Big-O algebra / 大 O 代数：低阶项、常数因子可忽略，嵌套成本常通过乘法组合。 [lec04]
- Master Theorem / 主定理：用于求解 `T(n) = aT(n/b) + f(n)` 形式的 divide-and-conquer recurrence。 [lec11]
- Algorithm-specific bounds / 典型复杂度：Binary Search `O(log n)`，Merge Sort `O(n log n)`，QuickSort worst-case `O(n^2)`，Randomized QuickSort expected `O(n log n)`，Heapify `O(n)`，AVL search `O(log n)`。 [lec06, lec10, lec11, lec13, lec15]

### Prerequisite Foundations / 前置基础

- Logarithms and exponentials / 对数与指数：理解 binary search、tree height、recurrence depth 和 growth comparison 的基础。 [Prereq]
- Summations / 求和：用于 loop counting、recurrence expansion、heapify analysis 和 quadratic algorithms。 [Prereq]
- Limits / 极限：用于比较增长率和使用 L'Hopital's rule。 [Prereq]
- Mathematical induction / 数学归纳法：用于证明 recursive correctness 和 recurrence solution。 [Prereq]
- Floor and ceiling notation / 向下取整与向上取整：用于 binary search、divide-and-conquer splitting 和 array index reasoning。 [Prereq]

### Beyond-Lecture Extensions / 进阶延伸

- Formal amortized analysis / 形式化摊还分析：证明 dynamic array、splay tree 等结构的一串操作平均成本。 [Beyond Lec]
- Average-case analysis / 平均情况分析：基于 input distribution 分析算法成本。 [Beyond Lec]
- Decision-tree lower bounds / 决策树下界：证明 comparison sorting 至少需要 `Omega(n log n)` comparisons。 [Beyond Lec]
- Smoothed analysis / 平滑分析：研究 worst-case input 在轻微扰动后的表现。 [Beyond Lec]
- Parameterized complexity / 参数化复杂度：除 `n` 外，用额外参数分析问题难度。 [Beyond Lec]

### Connections / 关联

- Complexity analysis 是后续所有 algorithm design techniques 的共同度量语言。 [lec03, lec04, lec05, lec06, lec09, lec10, lec11, lec13, lec15]
- Recurrence 把 recursion、decrease-and-conquer、divide-and-conquer、binary search、merge sort、quicksort、closest pair 和 tree height 联系在一起。 [lec04, lec06, lec10, lec11, lec12, lec15]

## Data Structures And Representation Layer / 数据结构与表示层

Covered lectures: [lec02, lec07, lec08, lec12, lec13, lec14, lec15]

### Core Structure / 核心结构

- Array / 数组：连续 memory cells，支持快速 index access，但长度固定，middle insertion/deletion 通常昂贵。 [lec02]
- Linked list / 链表：由 nodes 和 links 组成，已知位置时 insertion/deletion 便宜，但 positional access 较慢。 [lec02]
- Iterative processing / 迭代处理：逐步扫描 array 或 linked list，常产生 linear-time algorithms。 [lec02]
- Recursive processing / 递归处理：先解决 smaller sub-instance，再用其结果解决当前问题。 [lec02, lec06]
- Stack / 栈：LIFO ADT，支持 push、pop、top、isEmpty。 [lec02, lec08]
- Queue / 队列：FIFO ADT，支持 enqueue、dequeue、head、isEmpty。 [lec02, lec08]
- Priority queue / 优先队列：按 priority 取出 highest-priority item 的 ADT。 [lec13]
- Graph representation / 图表示：adjacency matrix 与 adjacency list 在 space cost 和 neighbour scanning 上有不同 tradeoff。 [lec07]
- Heap representation / 堆表示：complete binary tree 可以用 level-order array 紧凑存储。 [lec13]
- BST representation / 二叉搜索树表示：用 tree-guided navigation 替代线性扫描，加速 dictionary search。 [lec14]
- Balanced tree representation / 平衡树表示：AVL tree 和 2-3 tree 通过 height guarantee 保护 search efficiency。 [lec15]

### Prerequisite Foundations / 前置基础

- Memory addresses and references / 内存地址与引用：理解 arrays、linked lists 和 pointer-like structures 的基础。 [Prereq]
- Index arithmetic / 下标运算：用于 arrays、binary search、heap parent-child formulas 和 partitioning。 [Prereq]
- ADT versus implementation / 抽象类型与实现分离：理解 stack、queue、priority queue 的 contract 可以由不同结构实现。 [Prereq]
- Invariants / 不变量：用于证明 heap push/pop、BST search、AVL rotations 等操作后结构仍合法。 [Prereq]

### Beyond-Lecture Extensions / 进阶延伸

- Hash table / 哈希表：dictionary structure，在合适 hashing 下 expected `O(1)` search、insert、delete。 [Beyond Lec]
- Union-find / 并查集：维护 disjoint sets，支持近似常数摊还复杂度操作。 [Beyond Lec]
- Skip list / 跳表：随机化 ordered structure，expected `O(log n)` search 和 update。 [Beyond Lec]
- Cache-aware data structures / 缓存感知数据结构：考虑 memory hierarchy，而不只看 RAM model 的 unit cost。 [Beyond Lec]

### Connections / 关联

- 同一个 ADT 可以有多种 implementation，并对应不同 operation costs，例如 priority queue 可以用 array、list、heap 等实现。 [lec13]
- Graph algorithm 的成本强烈依赖 representation：adjacency list 适合 sparse graphs，adjacency matrix 适合 constant-time edge lookup。 [lec07, lec08]
- Tree balance 是一种 representation invariant，用来保护 asymptotic search time。 [lec14, lec15]

## Algorithm Design Paradigms / 算法设计范式

Covered lectures: [lec02, lec05, lec06, lec09, lec10, lec11, lec12, lec14]

### Brute Force And Exhaustive Search / 暴力法与穷举搜索

- Brute force / 暴力法：直接从 problem definition 出发，检查最自然的 candidates。 [lec05]
- Selection sort as brute force / 选择排序作为暴力法：反复找剩余元素中的 minimum 并放到前面。 [lec04, lec05, lec06]
- Brute-force string matching / 暴力字符串匹配：检查 text 中每个可能 alignment，worst-case `O(mn)` comparisons。 [lec05]
- Brute-force closest pair / 暴力最近点对：检查所有 point pairs，得到 `O(n^2)` time。 [lec05]
- Exhaustive search / 穷举搜索：系统生成所有 possible solutions，再 evaluate 并保留最优或可行解。 [lec05]
- Travelling Salesman Problem, TSP / 旅行商问题：枚举所有 tours 概念简单，但规模增长极快。 [lec05]
- Knapsack problem / 背包问题：subset enumeration 展示 exponential candidate space。 [lec05]
- Hamiltonian versus Eulerian tours / 哈密顿回路与欧拉回路：表面相似，但算法难度差异巨大。 [lec05]
- Brute-force role / 暴力法定位：适合作为 prototype、小输入解法、baseline solution 和 correctness comparison。 [lec05]

### Recursion / 递归

- Recursive design / 递归设计：通过 base case 与 inductive case 定义算法。 [lec06]
- Base case / 基础情形：处理 `n = 0`、`n = 1` 等 trivial sizes。 [lec06]
- Inductive case / 归纳情形：把当前 instance 化为一个或多个 smaller instances。 [lec06]
- Binary search via recursion / 递归版二分查找：每次丢弃 sorted range 的一半。 [lec06, lec10]
- Recursive selection sort / 递归版选择排序：找 minimum、放到首位、递归排序剩余 suffix。 [lec06]
- Power computation / 幂计算：naive recursion 是 `O(n)`，exponent halving 可做到 `O(log n)`。 [lec06, lec10]
- Recursion-cost link / 递归与成本关系：recursive structure 通常自然对应 recurrence relation。 [lec04, lec06]

### Decrease-And-Conquer / 减治法

- Decrease by a constant / 常数减治：用 size `n-1` 的解构造 size `n` 的解。 [lec09]
- Topological sorting by removal / 删除法拓扑排序：反复选择 zero in-degree node，加入 order，再删除它。 [lec09]
- Topological sorting by DFS / DFS 拓扑排序：利用 finishing order 构造 DAG 的 linearization。 [lec09]
- Improved topological sorting / 改进拓扑排序：维护 zero in-degree nodes，避免每轮重复扫描。 [lec09]
- Decrease by a factor / 因子减治：每步按固定比例缩小问题，常带来 logarithmic behaviour。 [lec10]
- Binary search / 二分查找：每次把 sorted array 的搜索范围缩小约一半。 [lec06, lec10]
- Fast exponentiation / 快速幂：每次把 exponent 约减半。 [lec06, lec10]
- Partitioning / 划分：围绕 pivot 重排 array，得到 rank/order 信息。 [lec10]
- Lomuto partition / Lomuto 划分：使用 pivot 与 boundary index 的具体 partition method。 [lec10]
- QuickSelect / 快速选择：partition 后只进入包含 kth smallest 的一侧。 [lec10]
- Randomized QuickSelect / 随机化快速选择：random pivot 使 expected running time 达到 `O(n)`。 [lec10]

### Divide-And-Conquer / 分治法

- Divide-and-conquer strategy / 分治策略：divide instance、recursively solve sub-instances、combine results。 [lec11]
- Balanced splitting / 平衡划分：当 subproblems 大小接近时，分治通常更高效。 [lec11]
- Merge sort / 归并排序：递归排序左右两半，再用 linear-time merge 合并。 [lec11]
- Quick sort / 快速排序：选择 pivot，partition，然后递归排序两侧。 [lec11]
- Randomized quicksort / 随机化快速排序：random pivot 减少持续 bad partition 的风险，expected `O(n log n)`。 [lec11]
- Master Theorem / 主定理：求解常见 balanced divide-and-conquer recurrences。 [lec11]
- Closest pair divide-and-conquer / 最近点对分治：用 sorted lists 和 strip checking 把 2D closest pair 从 `O(n^2)` 改进到 `O(n log n)`。 [lec05, lec12]

### Transform-And-Conquer / 变治法

- Instance simplification / 实例简化：通过 preprocessing 让后续问题更容易。 [lec14]
- Presorting for uniqueness / 预排序检查唯一性：sort 后只需检查 adjacent elements。 [lec14]
- Presorting for mode finding / 预排序找众数：sort 后扫描 equal-value runs。 [lec14]
- Presorting for repeated search / 预排序多次搜索：一次 sorting 成本换取后续多次 binary search。 [lec14]
- Anagram detection / 变位词检测：把每个 word 转成 sorted-character representation 后分组。 [lec14]
- Representational change / 表示改变：换一种 data representation，例如 BST，使操作更快。 [lec14]
- Problem reduction / 问题归约：把问题转成已知工具能解决的另一个问题。 [lec14]

### Prerequisite Foundations / 前置基础

- Combinatorics / 组合数学：理解 permutations、subsets、exhaustive search、TSP、knapsack 的候选空间。 [Prereq]
- Induction / 归纳法：证明 recursive correctness 和 recurrence solutions。 [Prereq]
- Loop invariants / 循环不变量：证明 partitioning、selection sort、heap operations 和 traversal correctness。 [Prereq]
- Random variables and expectation / 随机变量与期望：理解 Randomized QuickSelect 和 Randomized QuickSort 分析。 [Prereq]

### Beyond-Lecture Extensions / 进阶延伸

- Backtracking / 回溯：递归构造 candidates，并在不可能时提前剪枝。 [Beyond Lec]
- Branch and bound / 分支限界：用 bounds 剪掉不可能优于当前解的搜索分支。 [Beyond Lec]
- Dynamic programming / 动态规划：通过 memoization 或 tabulation 避免重复子问题计算。 [Beyond Lec]
- Greedy algorithms / 贪心算法：每步选择 locally optimal choice 构造解。 [Beyond Lec]
- Median-of-medians / 中位数的中位数：deterministic linear-time selection，worst-case `O(n)`。 [Beyond Lec]
- Approximation algorithms / 近似算法：为 hard optimization problems 快速求 reasonably good solutions。 [Beyond Lec]

### Connections / 关联

- Brute force 常提供第一个 correct baseline，后续范式则解释如何 improve it。 [lec05, lec10, lec11, lec12, lec14]
- Recursion 是 decrease-and-conquer 与 divide-and-conquer 的共同机制。 [lec06, lec09, lec10, lec11]
- Transform-and-conquer 常通过 choosing better representation 实现，例如 sorting、BST、heap 或 graph adjacency structures。 [lec07, lec13, lec14]

## Searching, Selection, And Ordering / 搜索、选择与排序

Covered lectures: [lec02, lec04, lec05, lec06, lec10, lec11, lec13, lec14, lec15]

### Core Structure / 核心结构

- Sequential search / 顺序搜索：从头扫描 array 或 list，直到找到 item 或结构结束。 [lec02, lec14]
- Dictionary search problem / 字典搜索问题：判断 target value 是否属于 sorted array 中的 set。 [lec06]
- Binary search / 二分查找：在 sorted array 中反复比较 middle element。 [lec06, lec10]
- Presorted search tradeoff / 预排序搜索权衡：当同一数据要进行 many queries 时，先 sort 再 binary search 可能更划算。 [lec14]
- BST search / 二叉搜索树搜索：与 root 比较，然后进入 left 或 right subtree。 [lec14]
- Balanced BST search / 平衡 BST 搜索：保持 logarithmic height，使 search、insert、update 更稳定。 [lec15]
- kth selection problem / 第 k 小选择问题：返回 kth smallest item，而不一定完整排序。 [lec10]
- QuickSelect / 快速选择：用 partition 隔离 pivot rank，只递归进入相关 partition。 [lec10]
- Randomized selection / 随机化选择：random pivot 使 QuickSelect expected `O(n)`。 [lec10]
- Sorting problem / 排序问题：把 comparable items 排成 non-decreasing order。 [lec04, lec05, lec11]
- Sorting properties / 排序性质：in-place、stable、input-insensitive 分别描述 memory use、equal-key order 与 input-dependent performance。 [lec05]
- Selection sort / 选择排序：in-place 且 input-insensitive，time quadratic，但 swaps 较少。 [lec04, lec05, lec06]
- Merge sort / 归并排序：divide-and-conquer sorting，`O(n log n)` time，merge 阶段 linear。 [lec11]
- Comparison sorting lower bound / 比较排序下界：任何 comparison-based sorting 需要 `Omega(n log n)` comparisons。 [lec11]
- Quick sort / 快速排序：partition-based sorting，通常很快，但 bad pivots 会导致 worst-case `O(n^2)`。 [lec11]
- Randomized quicksort / 随机化快速排序：用 random pivot 获得 expected `O(n log n)`。 [lec11]
- Heapsort / 堆排序：heapify 后反复 pop，worst-case `O(n log n)`，in-place，但 not stable。 [lec13]
- Priority ordering / 优先级排序：priority queue 用 priority rule 泛化 stack 和 queue 的取出顺序。 [lec13]

### Prerequisite Foundations / 前置基础

- Total order and comparison / 全序与比较：sorting、binary search、BST、heap、selection 的共同基础。 [Prereq]
- Permutations / 排列：理解 sorting 是对输入 items 的重新排列。 [Prereq]
- Rank and order statistics / 秩与顺序统计量：理解 kth selection 与 pivot position。 [Prereq]
- Stability / 稳定性：当 equal keys 携带附加信息时，relative order 是否保留很重要。 [Prereq]

### Beyond-Lecture Extensions / 进阶延伸

- Counting sort / 计数排序：当 keys 位于小整数范围时可达 `O(n + k)`。 [Beyond Lec]
- Radix sort / 基数排序：按 digit 逐位排序，常用于 fixed-width keys。 [Beyond Lec]
- Bucket sort / 桶排序：当 input 分布较均匀且范围已知时有效。 [Beyond Lec]
- Introsort / 内省排序：从 quicksort 开始，必要时切换策略保证 `O(n log n)`。 [Beyond Lec]
- Timsort / Tim 排序：实际工程常用 stable sorting，利用已有 runs。 [Beyond Lec]
- Order-statistic tree / 顺序统计树：augmented balanced tree，支持 `O(log n)` rank 与 selection queries。 [Beyond Lec]

### Connections / 关联

- Binary search、BST search、QuickSelect 都通过 comparisons 丢弃或隔离大块 search space。 [lec06, lec10, lec14]
- Sorting 既是目标问题，也是 uniqueness、mode finding、repeated search、anagrams、closest pair 的 transform step。 [lec11, lec12, lec14]
- Heap 把 priority queue 与 sorting 连接到 heapsort。 [lec13]

## Graphs And Graph Algorithms / 图与图算法

Covered lectures: [lec01, lec05, lec07, lec08, lec09]

### Core Structure / 核心结构

- Graph model / 图模型：`G = <V, E>`，vertices 表示对象，edges 表示对象之间的关系。 [lec07]
- Graph modelling / 图建模：maze、road networks、social networks、user-item networks、webpages 和 optimization problems 都可建模为 graph。 [lec01, lec07]
- Directed graph / 有向图：edge 有方向，因此有 in-neighbour 和 out-neighbour。 [lec07]
- Undirected graph / 无向图：edge 对两个 vertices 对称连接。 [lec07]
- Degree concepts / 度数概念：undirected degree 计 incident edges，directed graph 使用 in-degree 和 out-degree。 [lec07]
- Path / 路径：由 edges 连接的一串 vertices。 [lec07]
- Path length / 路径长度：通常指 path 中 edges 的数量。 [lec07]
- Cycle / 环：在相应规则下回到已访问 vertex 的 path。 [lec07]
- Connectedness / 连通性：描述 vertices 是否位于同一个 reachable component。 [lec07]
- DAG / 有向无环图：directed acyclic graph，是 dependency scheduling 与 topological sorting 的核心结构。 [lec07, lec09]
- Weighted graph / 带权图：edges 带 numerical weights，可表示 distance、cost、capacity 等。 [lec07]
- Sparse versus dense graph / 稀疏图与稠密图：sparse graph 满足 `|E| in O(|V|)`，dense graph 有更多 edges。 [lec07]
- Tree as graph / 树作为图：tree 是 connected undirected acyclic graph。 [lec07]
- Adjacency matrix / 邻接矩阵：存储所有 vertex pairs，edge lookup 快，但 sparse graph 下浪费空间。 [lec07]
- Adjacency list / 邻接表：存储每个 vertex 的 neighbours，通常更适合 sparse graphs。 [lec07]
- Unified graph traversal / 统一遍历框架：同一 traversal framework 中，用 stack 得到 DFS，用 queue 得到 BFS。 [lec08]
- DFS / Depth-First Search / 深度优先搜索：沿路径深入，产生 DFS tree 或 DFS forest。 [lec08]
- BFS / Breadth-First Search / 广度优先搜索：按层扩展，产生 BFS tree 或 BFS forest。 [lec08]
- Visited/traversed flags / 访问标记：记录 vertices 是否 discovered 或 fully processed。 [lec08]
- Disconnected graph traversal / 非连通图遍历：从未遍历 vertex 重新启动 traversal，直到覆盖全图。 [lec08]
- Traversal cost / 遍历复杂度：adjacency list 下为 `O(|V| + |E|)`，adjacency matrix 扫描可能为 `O(|V|^2)`。 [lec08]
- Topological sorting / 拓扑排序：把 DAG linearize，使每条 directed edge 都从 earlier node 指向 later node。 [lec09]
- Topological sorting by DFS / DFS 拓扑排序：利用 finishing order 构造依赖顺序。 [lec09]
- Topological sorting by decrease-and-conquer / 减治法拓扑排序：反复移除 zero in-degree nodes。 [lec09]
- TSP and Hamiltonian tours / TSP 与哈密顿回路：用于说明 graph problems 与 exhaustive search/hardness。 [lec05]
- Eulerian tours / 欧拉回路：与 Hamiltonian tours 对比，说明相似形式不代表相似难度。 [lec05]

### Prerequisite Foundations / 前置基础

- Sets and Cartesian products / 集合与笛卡尔积：理解 `V` 与 `E subset V x V` 的形式定义。 [Prereq]
- Relations / 关系：理解 edges 本质上是 vertices 之间的关系。 [Prereq]
- Stack and queue mechanics / 栈与队列机制：DFS 与 BFS 的执行基础。 [Prereq]
- Sum of degrees / 度数求和：理解 adjacency-list traversal cost 的基础。 [Prereq]
- Partial orders / 偏序：理解 DAG dependencies 与 topological sorting 的数学背景。 [Prereq]

### Beyond-Lecture Extensions / 进阶延伸

- Dijkstra's algorithm / Dijkstra 算法：non-negative weighted graph 的 single-source shortest paths。 [Beyond Lec]
- Bellman-Ford algorithm / Bellman-Ford 算法：允许 negative edges，并可检测 negative cycle。 [Beyond Lec]
- Floyd-Warshall algorithm / Floyd-Warshall 算法：all-pairs shortest paths，基于 dynamic programming。 [Beyond Lec]
- A* search / A 星搜索：使用 heuristic 的 goal-directed shortest-path search。 [Beyond Lec]
- Kruskal's algorithm / Kruskal 算法：通过 sorting edges 与 union-find 求 minimum spanning tree。 [Beyond Lec]
- Prim's algorithm / Prim 算法：通过 priority queue 扩展 minimum spanning tree。 [Beyond Lec]
- Strongly connected components / 强连通分量：directed graph 中互相 reachable 的 vertex groups。 [Beyond Lec]
- Maximum flow / 最大流：建模 capacity-constrained routing 与 matching problems。 [Beyond Lec]

### Connections / 关联

- DFS 是 graph traversal 与 recursion/stack thinking 的直接交汇点。 [lec06, lec08]
- BFS on trees 与 level-order traversal 是同一种按层访问思想。 [lec08, lec12]
- Topological sorting 同时使用 graph concepts、DFS、in-degree tracking 和 decrease-and-conquer。 [lec07, lec08, lec09]
- Graph representation choice 会直接改变 traversal cost。 [lec07, lec08]

## Trees, Heaps, And Balanced Search Structures / 树、堆与平衡搜索结构

Covered lectures: [lec07, lec12, lec13, lec14, lec15]

### Core Structure / 核心结构

- Tree / 树：connected undirected acyclic graph。 [lec07]
- Rooted tree / 有根树：以指定 root 为中心，按 distance from root 组织 nodes。 [lec07]
- Parent and child / 父子关系：表达 rooted tree 中的一步层级关系。 [lec07]
- Leaf / 叶子：没有 children 的 node。 [lec07]
- Subtree / 子树：以某个 node 为 root 的局部 tree。 [lec07]
- Ancestor and descendant / 祖先与后代：描述 root-to-node path 上的上下关系。 [lec07]
- Node depth / 节点深度：proper ancestors 的数量。 [lec07]
- Tree height / 树高：maximum depth，即最长 root-to-leaf path 的 edge count。 [lec07, lec12]
- Binary tree / 二叉树：每个 node 最多有两个 children 的 rooted tree。 [lec12]
- Full binary tree / 满二叉树：每个 node 要么没有 child，要么有两个 non-empty children。 [lec12]
- Complete binary tree / 完全二叉树：每层从左到右填充，支持 compact array storage。 [lec12, lec13]
- Empty tree / 空树：记作 `null`，height convention 对 recursive formulas 很有用。 [lec12, lec15]
- Preorder traversal / 前序遍历：root、left subtree、right subtree。 [lec12]
- Inorder traversal / 中序遍历：left subtree、root、right subtree。 [lec12]
- Postorder traversal / 后序遍历：left subtree、right subtree、root。 [lec12]
- Level-order traversal / 层序遍历：按 breadth-first layers 访问，可用 BFS 实现。 [lec08, lec12]
- Priority queue / 优先队列：支持 `getTop`、`pop`、`push`，按 priority 取出元素。 [lec13]
- Max binary heap / 最大二叉堆：complete binary tree，并满足 parent key 不小于 child keys。 [lec13]
- Heap array indexing / 堆的数组下标：complete structure 允许用 index formulas 找 parent 和 children。 [lec13]
- Bubble-up / 上浮：插入新元素后向 root 方向修复 heap order。 [lec13]
- Bubble-down / 下沉：删除或替换 root 后向 leaf 方向修复 heap order。 [lec13]
- Heap push and pop / 堆插入与删除：分别依赖 bubble-up 与 bubble-down 维护 heap condition。 [lec13]
- Heapify / 建堆：bottom-up 构建 heap，time complexity 为 `O(n)`。 [lec13]
- Heapsort / 堆排序：heapify 后反复 pop，worst-case `O(n log n)`。 [lec13]
- BST invariant / 二叉搜索树不变量：left subtree keys 小于 root，right subtree keys 大于 root。 [lec14]
- BST search / BST 搜索：根据 key comparison 递归进入 left 或 right subtree。 [lec14]
- BST insertion / BST 插入：像 search 一样走到 fringe，在应该出现的位置插入。 [lec14]
- Inorder traversal of BST / BST 中序遍历：输出 sorted order。 [lec14]
- Tree height dependency / 树高依赖：普通 BST 的 search cost 取决于 height，极端情况下可退化为 linear。 [lec14]
- AVL tree / AVL 树：BST，且每个 node 的 balance factor 只能是 -1、0、1。 [lec15]
- AVL rotations / AVL 旋转：R、L、LR、RL rotations 用于插入后恢复 balance。 [lec15]
- AVL height guarantee / AVL 高度保证：AVL balance 使 depth 保持 `Theta(log n)`。 [lec15]
- Red-black tree / 红黑树：另一类 balanced BST，用 colour-based balance 维护高度。 [lec15]
- 2-3 tree / 2-3 树：node 可存 one or two keys，并有 two or three children。 [lec15]
- 2-3 tree insertion / 2-3 树插入：在 leaf 插入，若 3-node overflow 则 split 并可能向上传播。 [lec15]
- 2-3 tree search cost / 2-3 树搜索成本：height 保持 logarithmic，因此 search 高效。 [lec15]

### Prerequisite Foundations / 前置基础

- Recursion on subtrees / 子树递归：理解 height、traversal、BST search、BST insertion 的基础。 [Prereq]
- Binary tree height / 二叉树高度：连接 tree shape 与 search cost 的关键。 [Prereq]
- Complete tree indexing / 完全树下标：理解 heap 为什么能用 array 表示。 [Prereq]
- Invariant preservation / 不变量保持：理解 heap condition、BST ordering、AVL balance、2-3 tree constraints。 [Prereq]
- Logarithmic height reasoning / 对数高度推理：理解 balanced trees 为什么能保护 search complexity。 [Prereq]

### Beyond-Lecture Extensions / 进阶延伸

- B-tree / B 树：database 和 file system 常用的 multi-way balanced search tree。 [Beyond Lec]
- B+ tree / B+ 树：B-tree variant，leaf 层连接，适合 range queries。 [Beyond Lec]
- Treap / 树堆：同时结合 BST order 与 heap priority 的 randomized BST。 [Beyond Lec]
- Splay tree / 伸展树：self-adjusting BST，amortized `O(log n)` operations。 [Beyond Lec]
- Pairing heap / 配对堆：实践中常见的 heap variant，摊还表现较好。 [Beyond Lec]
- Fibonacci heap / 斐波那契堆：priority queue，decrease-key 摊还复杂度优秀，常与 graph algorithms 关联。 [Beyond Lec]

### Connections / 关联

- Binary tree 加上不同 invariants，就得到 BST、heap、AVL tree、2-3 tree 等结构。 [lec12, lec13, lec14, lec15]
- Heap 虽然 tree-shaped，但核心目标是 priority ordering，不是 search ordering。 [lec13, lec14]
- BST 把 searching、sorting、tree traversal 和 transform-and-conquer representation change 连接起来。 [lec12, lec14]
- Balanced trees 是对 ordinary BST height 可能退化为 linear 的回应。 [lec14, lec15]

## Cross-Cutting Themes / 横向主线

Covered lectures: [lec01, lec02, lec03, lec04, lec05, lec06, lec07, lec08, lec09, lec10, lec11, lec12, lec13, lec14, lec15]

### Core Structure / 核心结构

- Correctness before efficiency / 正确性先于效率：算法必须先对所有 valid inputs 正确，再讨论 cost。 [lec01]
- Cost model discipline / 成本模型纪律：complexity claims 必须基于共同 computational model。 [lec03]
- Representation shapes algorithms / 表示决定算法形态：arrays、linked lists、graphs、heaps、trees 各自让不同 operations 变容易或变难。 [lec02, lec07, lec13, lec14, lec15]
- Invariants are the hidden backbone / 不变量是隐藏骨架：sorted order、heap order、BST order、AVL balance、visited flags、partition boundaries 都靠 invariant 维持正确性。 [lec08, lec10, lec13, lec14, lec15]
- Recursion and reduction recur everywhere / 递归与规模缩减反复出现：binary search、selection sort、QuickSelect、MergeSort、QuickSort、tree traversal、closest pair、balanced trees 都在 shrink 或 split problem。 [lec06, lec10, lec11, lec12, lec15]
- Worst-case versus expected guarantees / 最坏情况与期望保证：deterministic worst-case 与 randomized expected cost 回答的是不同性能问题。 [lec03, lec10, lec11]
- Preprocessing can be worth it / 预处理可能值得：presorting 或 building a data structure 用 upfront cost 换取后续 operations 加速。 [lec13, lec14, lec15]
- Similar surfaces can hide different complexity / 表面相似不等于复杂度相似：Hamiltonian 与 Eulerian tours 就是典型例子。 [lec05]

### Prerequisite Foundations / 前置基础

- Algorithm tracing / 算法手动追踪：理解 pseudocode 如何一步步改变 state。 [Prereq]
- Counterexamples / 反例意识：检验 invariant 或 algorithm claim 是否真的 always works。 [Prereq]
- Asymptotic judgement / 渐进判断力：判断 preprocessing、balancing、randomization、representation change 是否值得。 [Prereq]

### Beyond-Lecture Extensions / 进阶延伸

- Empirical benchmarking / 实证 benchmark：测量实际 runtime 和 memory behaviour。 [Beyond Lec]
- Formal verification / 形式化验证：用 machine-checkable logic 证明 program 或 algorithm correctness。 [Beyond Lec]
- Randomized algorithm design / 随机化算法设计：把 probability 作为 algorithmic resource。 [Beyond Lec]
- Data-structure augmentation / 数据结构增强：在结构中存额外 metadata，例如 subtree size 或 balance field，以支持更快 queries。 [Beyond Lec]

### Connections / 关联

- 本课程多数 improvement 都可以概括为三种 move：shrink input faster、split input better、change representation。 [lec09, lec10, lec11, lec14]
- 同一个问题常可经历多个层次：brute-force baseline、recursive formulation、complexity analysis、data-structure improvement。 [lec04, lec05, lec06, lec13, lec15]
